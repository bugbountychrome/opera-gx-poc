High-Impact Spoofing Fuzzer

Vektor: Intent Abuse, Data URI Race, RTL Override, Window Name.

Target Spoofing Domain

Gunakan domain yang ingin ditampilkan di address bar (contoh: https://accounts.google.com).

1. Intent Scheme + Download Freeze

Mencoba memicu download via Intent URL untuk membekukan address bar pada URL target asli.

2. Data URI Race (Meta Refresh)

Memuat UI palsu via Data URI, lalu memaksa address bar berubah ke target via redirect mikro-detik.

3. RTL / Unicode Override (CVE-2019-12278)

Memanipulasi visual address bar menggunakan karakter Right-to-Left Override (U+202E) dengan domain attacker.

4. Window Name Injection

Menguji apakah parameter nama window (`window.open`) bocor ke address bar pada engine Opera Mini.
